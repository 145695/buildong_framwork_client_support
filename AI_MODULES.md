# AI Modules & LLMs Used

## Speech-to-Text (STT)
- **NVIDIA Riva gRPC** - Whisper Large V3
  - Multi-language speech recognition
  - Cloud-based processing

## Translation
- **NVIDIA Nemotron** - Translation Model
  - Multi-language translation
  - Text sanitization
  - Conditional routing

## Intent Detection
- **Llama tuned** - Intent Classification
  - Intent recognition
  - Agent routing logic
  - Confidence scoring

## Knowledge Base LLMs
- **Mistral AI** - Primary LLM
  - Answer generation
  - Document reasoning
  - API: mistral-small model

- **Fallback LLM** - Backup System
  - Simple response generation
  - Error handling

## Text Embeddings
- **Sentence Transformers** - Vector Embeddings
  - Text vectorization
  - Semantic search
  - Document similarity

## Text-to-Speech (TTS)
- **Kokoro** - Primary TTS
  - Multi-language support
  - High-quality voice synthesis

- **Habibi-TTS** - Arabic TTS
  - Arabic language support
  - F5-TTS based

- **Google TTS (gTTS)** - Fallback TTS
  - Multi-language support
  - Backup option

## Vector Processing
- **FAISS** - Vector Search
  - Similarity search
  - Vector indexing
  - Fast retrieval

- **ChromaDB** - Vector Database
  - Document storage
  - Vector operations
  - Metadata management

## AI Models Summary
1. **Whisper Large V3** - Speech recognition
2. **Nemotron** - Translation
3. **Llama fine tuned** - Intent detection
4. **Mistral** - Knowledge base reasoning
5. **Sentence Transformers** - Embeddings
6. **Kokoro** - Text-to-speech
7. **Habibi-TTS** - Arabic TTS
8. **gTTS** - Fallback TTS
